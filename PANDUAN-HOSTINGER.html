Pindahkan KOBSHI ke Hostinger

Target website: https://kobshi.banuamentor.id
Target admin: https://kobshi.banuamentor.id/admin

Paket ini sudah menggunakan login email/password mandiri dan database MySQL. Domain utama banuamentor.id serta Starter Business Email tetap dipertahankan. Tidak ada password produksi di dalam paket.

1Unduh dan pahami isi paket

  1. Simpan ZIP dari ChatGPT ke komputer Anda.
  2. Ekstrak satu salinan untuk membaca panduan ini. Simpan juga ZIP asli untuk diunggah.
  3. ZIP berisi package.json pada tingkat teratas. Anda tidak perlu mengunggah folder satu per satu.

Konten berasal dari salinan database aktif pada waktu ekspor yang tercantum dalam migration/export-manifest.json: 9 produk, 2 jurnal, dan pengaturan website. Perubahan pada Sites setelah waktu tersebut tidak masuk otomatis.

2Buat aplikasi baru pada paket Business

  1. Masuk ke Hostinger hPanel.
  2. Buka Websites → Add Website → Deploy Web App.
  3. Pilih Upload your website files, lalu unggah ZIP KOBSHI.
  4. Jika dapat memilih alamat saat membuat aplikasi, gunakan kobshi.banuamentor.id. Jika belum tersedia, gunakan domain sementara Hostinger; subdomain dapat dihubungkan setelah deployment.
  5. Pilih hosting Business Web Hosting milik Anda.
Buat website/aplikasi baru untuk KOBSHI. Jangan menghapus atau mengganti website utama banuamentor.id. Jangan mengekstrak paket ini langsung ke public_html sebagai website HTML statis.

3Buat database MySQL khusus KOBSHI

  1. Buka pengelolaan hosting di hPanel, lalu Databases → Management. Pada antarmuka yang menempatkannya di dashboard website: Websites → Dashboard → Databases → Management.
  2. Buat database dengan nama pendek, misalnya kobshi, dan pengguna database khusus.
  3. Buat password database yang kuat dan simpan dalam pengelola password.
  4. Catat nama database lengkap dan username lengkap yang ditampilkan setelah dibuat. Hostinger biasanya menambahkan awalan akun; gunakan nama lengkap, bukan hanya kobshi.
  5. Catat alamat server database. Gunakan alamat yang diberikan hPanel; dokumentasi Hostinger menyebut localhost sebagai nilai yang biasanya dipakai.

Tabel dan konten awal akan dibuat otomatis ketika aplikasi pertama kali membuka database. Anda tidak perlu mengimpor JSON melalui phpMyAdmin. File migration/schema.sql disertakan sebagai rujukan skema.

Jika menu database belum tersedia karena aplikasi baru belum dibuat, selesaikan deployment awal dahulu, buat database dari panel hosting, lalu tambahkan variabel di tahap 5 dan restart aplikasi.

5Isi environment variables

Pada konfigurasi deployment atau dashboard aplikasi, buka Environment Variables. Tambahkan pasangan nama dan nilai berikut. Gunakan nilai asli milik Anda, tanpa tanda kutip tambahan.

Jangan mengirim password melalui chat atau memasukkannya ke GitHub. Simpan konfigurasi di hPanel. Setelah menyimpan perubahan konfigurasi, restart atau redeploy aplikasi agar nilai baru digunakan.

6Deploy dan hubungkan subdomain

  1. Tekan Deploy dan tunggu status berhasil. Jika gagal, buka build logs; simpan teks kesalahan tanpa password.
  2. Buka daftar Websites atau dashboard aplikasi KOBSHI, lalu pilih Connect domain.
  3. Masukkan kobshi.banuamentor.id, lalu konfirmasi.
  4. Ikuti catatan DNS yang diberikan Hostinger. Jika ada isian nama/host subdomain, isi kobshi. Nilai tujuan harus mengikuti panel; jangan menebak IP atau target CNAME.
  5. Pertahankan catatan domain utama @, www, dan email MX/SPF/DKIM. Jika ada catatan lama khusus kobshi yang bentrok, ubah hanya catatan subdomain tersebut.
  6. Tunggu domain terhubung dan HTTPS aktif. Hostinger menyebut proses DNS dapat membutuhkan hingga 24 jam dan SSL dipasang otomatis setelah koneksi selesai.
  7. Pastikan SITE_URL sudah menjadi https://kobshi.banuamentor.id, lalu restart.

7Login dan periksa fitur

  1. Buka https://kobshi.banuamentor.id/admin.
  2. Masukkan ADMIN_EMAIL dan ADMIN_PASSWORD yang Anda atur.
  3. Pastikan 9 produk, 2 jurnal, dan logo asli tersedia.
  4. Edit harga salah satu produk, simpan, lalu buka website untuk memastikan hasilnya berubah.
  5. Buat satu produk uji dan unggah foto JPG/PNG/WebP maksimal 4 MB. Gunakan gambar sekitar 1 MB atau lebih kecil agar ringan.
  6. Buat jurnal sebagai draf; pastikan pengunjung tidak melihatnya. Centang Terbitkan dan periksa lagi.
  7. Uji tombol WhatsApp dan tiga produk awal + Tampilkan Selengkapnya.
  8. Restart aplikasi, lalu pastikan konten dan foto unggahan tetap ada. Hapus konten uji setelah pemeriksaan.
  9. Di tab Akun Admin, Anda dapat mengganti password. Tombol Keluar mengakhiri sesi perangkat saat ini.

Sesi login berlaku hingga 7 hari pada perangkat yang sama. Login ini mandiri dan tidak menggunakan ChatGPT. Password disimpan dalam bentuk hash; sesi perangkat lain dikeluarkan saat password diganti.

8Backup dan pembaruan

  • Aktifkan/periksa backup hosting dan database sesuai fasilitas paket. Backup database harus mencakup tabel images karena foto unggahan disimpan di sana.
  • Simpan ZIP kode dan ekspor database sebelum memperbarui aplikasi.
  • Untuk pembaruan, unggah kode baru melalui deployment aplikasi. Tetap gunakan database yang sama; jangan membuat ulang database atau menghapus penanda seeded.
  • Jangan menaikkan ADMIN_PASSWORD_VERSION kecuali sedang memulihkan password.
  • Versi Sites tetap tersedia selama Anda menyelesaikan perpindahan. Kedua versi tidak menyinkronkan perubahan otomatis; tentukan versi Hostinger sebagai tempat pengelolaan setelah uji selesai.

Jika lupa password admin

  1. Buka Environment Variables di hPanel aplikasi KOBSHI.
  2. Isi ADMIN_PASSWORD dengan password baru yang kuat.
  3. Naikkan ADMIN_PASSWORD_VERSION, misalnya dari 1 menjadi 2.
  4. Restart aplikasi, buka website sekali, lalu login dengan password baru. Seluruh sesi sebelumnya dikeluarkan. Konten tetap tersimpan.

Jika Anda sekaligus mengubah ADMIN_EMAIL, naikkan versi password juga agar alamat login diperbarui. Pemulihan ini menggunakan akses hPanel; pengiriman email reset belum digunakan.
